# SHA-VERSE

SHA-VERSE is a unified AI-powered social ecosystem.

## Modules

- Home Feed
- Movion (Video Platform)
- NovaChat (AI Chat)
- Bookshelf
- Groups
- Profile System

## Tech Stack

- React + TypeScript
- Supabase (Auth, Database, Realtime)
- GitHub (Version Control)

## Local Setup

npm install
npm run dev
